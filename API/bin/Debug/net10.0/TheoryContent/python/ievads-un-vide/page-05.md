# Neliels starts

Pamēģini uzrakstīt programmu, kas pajautā lietotāja vārdu un pasveicina viņu. Datu ievadei izmanto `input`.

```python
name = input("Kā tevi sauc? ")
print("Prieks iepazīties, " + name + "!")
```

`input` vienmēr atgriež tekstu. Pat ja lietotājs ievada skaitli, Python to sākumā uztver kā virkni. Vēlāk redzēsi, kā tekstu pārveidot par skaitli ar `int` vai `float`.

Mazs uzdevums:

1. Izveido failu `start.py`.
2. Pajautā lietotāja vārdu.
3. Pajautā mīļāko programmēšanas valodu.
4. Izvadi teikumu, kurā izmantotas abas atbildes.

Piemērs:

```text
Sveika, Laura! Python ir laba izvēle.
```

Šajā brīdī svarīgākais ir pierast pie cikla: uzraksti kodu, palaid, izlasi rezultātu, salabo. Programmēšana nav minēšana, tā ir pakāpeniska pārbaude.
