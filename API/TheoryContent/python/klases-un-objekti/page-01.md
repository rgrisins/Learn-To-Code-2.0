# Objekti

Python gandrīz viss ir objekts: teksts, skaitļi, saraksti, funkcijas. Objektam ir dati un darbības, kuras ar to var veikt.

```python
name = "python"
print(name.upper())
```

`name` ir teksta objekts, un `upper` ir metode, kas atgriež tekstu ar lielajiem burtiem.

Klases ļauj definēt pašam savus objektu tipus. Tas ir noderīgi, ja programmā ir jēdzieni ar īpašībām un darbībām, piemēram, lietotājs, kurss, uzdevums vai pasūtījums.

Objektorientētā programmēšana nav obligāta katrai mazai programmai. Ja pietiek ar funkcijām un vārdnīcām, tas ir labi. Klases kļūst vērtīgas, kad dati un ar tiem saistītā uzvedība atkārtojas daudzās vietās.

Mērķis nav rakstīt klases visur, bet saprast, kad tās palīdz padarīt kodu skaidrāku.
