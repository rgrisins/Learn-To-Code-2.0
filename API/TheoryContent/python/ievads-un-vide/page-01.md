# Kas ir Python

Python ir programmēšanas valoda, kuru bieži izmanto kā pirmo valodu, jo tā ļauj ideju pierakstīt īsi un salasāmi. Tā ir piemērota nelieliem skriptiem, datu apstrādei, tīmekļa lietotnēm, automatizācijai, testēšanai un arī mākslīgā intelekta projektos.

Python programmu parasti izpilda interpretators. Tas nozīmē, ka kods nav obligāti jāpārveido atsevišķā izpildāmā failā pirms palaišanas. Tu uzraksti failu, piemēram, `hello.py`, un palaid to ar komandu:

```python
print("Sveika, pasaule!")
```

Svarīga Python īpašība ir atkāpes. C citās valodās koda bloki bieži tiek apvilkti ar figūriekavām, bet Python izmanto vienādu atstarpi rindas sākumā. Tas padara kodu vizuāli tīru, bet arī prasa precizitāti.

Šajā kursā mērķis nav iemācīties visu uzreiz. Svarīgāk ir saprast pamata domāšanas veidu: programma saņem datus, veic darbības un dod rezultātu.
