# Kāpēc vajag funkcijas

Funkcija ir nosaukts koda gabals, kuru var izsaukt vairākas reizes. Tā palīdz sadalīt programmu mazākās daļās.

```python
def greet():
    print("Sveiki!")

greet()
greet()
```

Funkcijas ļauj izvairīties no atkārtošanās. Ja viena darbība mainās, labāk to labot vienā funkcijā, nevis daudzās vietās.

Labs funkcijas nosaukums pasaka, ko funkcija dara:

```python
def calculate_total():
    ...
```

Ja funkcijas nosaukumā gribas lietot "un", piemēram, `load_and_clean_and_save`, tā var būt zīme, ka funkcija dara pārāk daudz.

Funkcijas ir arī domāšanas rīks. Tu vari vispirms uzrakstīt, kādām darbībām programmā jānotiek, un pēc tam aizpildīt katru funkciju ar detaļām.
